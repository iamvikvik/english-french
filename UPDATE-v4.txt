Версия 4: прогресс и французский

В заучивании два счётчика:
Пройдено — карточки, на которые уже был дан ответ (включая ошибки).
Выучено — карточки, достигшие полного уровня освоения.
Полоса теперь соответствует «Пройдено». Повторный ответ на ту же карточку не увеличивает количество разных пройденных карточек.
Существующий частичный прогресс учитывается по сохранённым уровням и ошибкам. Сброс данных не нужен.

Во French автоматически добавляется один набор «Урок 1, 2, 3» из 161 слова и фразы. Исходный PDF можно открыть в этом разделе. Повторное открытие приложения не дублирует набор. Если набор удалён, его можно добавить снова в настройках.

Установка: сначала сохрани резервную копию приложения. Распакуй архив, загрузи его содержимое в корень прежнего репозитория GitHub с заменой файлов, затем Commit changes. Дождись публикации и открой приложение заново с интернетом. В настройках должна появиться надпись «Версия 4 · Прогресс и французский».
Не очищай данные браузера: они содержат твои наборы и прогресс.
