# English / French — A0 + A1

Обновление: уровень A0 «Английский по плейлистам» расположен перед A1. 50 уроков с карточками из предоставленного PDF; исходный конспект доступен в A0. Повторяющиеся пары внутри одного урока исключены. Страницы с тестами остаются в PDF.

## Как обновить существующий сайт
1. На всякий случай сохрани резервную копию в приложении: Настройки → Резервная копия.
2. Распакуй ZIP и загрузи все файлы из него в корень прежнего репозитория GitHub, заменив одноимённые файлы. Сам ZIP загружать не нужно.
3. Сохрани изменения (Commit changes) и дождись завершения публикации GitHub Pages.
4. Открой прежний адрес сайта с интернетом и обнови страницу. Если открыта старая версия, закрой приложение и открой его снова.

A0 добавится автоматически и только один раз. Существующие A1, собственные наборы и прогресс сохраняются при использовании прежнего адреса сайта и того же браузера. Не очищай данные сайта. Удалённые уроки можно вернуть в настройках.

Вкладки: A0 → A1 → Мои наборы. Поиск работает по всем наборам выбранного языка. Французский раздел сохранён. Режимы карточек, заучивания, правописания, диктанта, теста и подбора доступны для A0.
