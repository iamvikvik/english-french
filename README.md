# English / French — версия 3

## Установка обновления
1. В приложении сохрани резервную копию: Настройки → Резервная копия.
2. Распакуй архив. Загрузи все файлы из него в корень прежнего репозитория GitHub с заменой одноимённых файлов. Не загружай сам ZIP и не создавай вложенную папку.
3. Нажми Commit changes, дождись публикации GitHub Pages, закрой и снова открой приложение с интернетом.
4. Внизу настроек должна появиться надпись «Версия 3 · Карточки и заучивание».

## Карточки
Открой урок → Карточки. Выбери лицевую сторону: изучаемый язык или русский. Нажатие переворачивает карточку. Свайп влево означает «Ещё учу», вправо — «Помню». Прогресс сохраняется. Можно отменить последний ответ и повторить только незнакомые карточки.

## Заучивание
Открой урок → Заучивание. Выбери язык ответа и один или несколько типов вопросов: карточки, выбор ответа, сборка по буквам, ввод с клавиатуры. Настройки сохраняются отдельно для каждого урока. Для длинной фразы буквы собираются слово за словом. Французские акценты сохраняются. Кнопки озвучки у вариантов ответа не выбирают ответ.

Аудирование и диктант — дополнительные режимы с явно указанным направлением: в аудировании ответ русский, в диктанте — изучаемый язык.

Английский и французский остаются отдельными разделами. A0 и A1 сохранены. Настройки уроков включаются в резервную копию. Существующие наборы и прогресс сохраняются при обновлении по прежнему адресу в том же браузере. Не очищай данные сайта.

Проверено в мобильном размере Chromium: свайпы, отмена, сохранение настроек после перезагрузки, выбор только включённых типов вопросов и направлений, сборка букв с повторами и французскими акцентами, вызов озвучки отдельно от выбора ответа. Голос и его качество определяются голосами устройства; реальный iPhone отдельно не тестировался.
