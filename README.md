# English / French

Личное приложение для изучения английского и французского: свои наборы слов и фраз, озвучка, заучивание, правописание, диктант, тест, подбор, интервальное повторение. Данные хранятся только на телефоне.

Загрузи все файлы в корень репозитория и включи GitHub Pages (Settings → Pages → Deploy from a branch → main → /root).
